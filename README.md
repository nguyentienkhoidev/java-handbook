# java-handbook

A comprehensive guide and roadmap for Java Backend Development, scraped from FoxDev.

## Current Contents

Here is the current structure of the handbook, categorized by technology:

- **java-core**: 81 bài học (Java Fundamentals, OOP, Collections, Multithreading, Exception Handling, Java 8+ features).
- **spring-boot**: 19 bài học (Cơ bản đến nâng cao về Spring Boot, RESTful APIs, Spring Data JPA).
- **microservices**: 9 bài học (Kiến trúc Microservices, giao tiếp giữa các services, API Gateway).
- **sql**: 26 bài học (PostgreSQL cơ bản đến nâng cao, query tối ưu, transactions, đánh index).
- **nosql**: 28 bài học (MongoDB, Redis, Cassandra, thiết kế Schema NoSQL, performance).
- **ai-database**: 16 bài học (Vector database, Elasticsearch, pgvector).
- **git**: 18 bài học (Quản lý mã nguồn, branch, merge, rebase, giải quyết conflict).
- **docker**: 6 bài học (Containerization, Image, Volume, Docker Compose).
